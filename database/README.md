# Database

Put the exported database file here as `room_booking_ai.sql`.

How to export it from XAMPP:

1. Open http://localhost/phpmyadmin
2. Click the `room_booking_ai` database on the left
3. Click **Export**, keep "Quick" and "SQL", then click **Export**
4. Save the file in this folder as `room_booking_ai.sql`

Before committing, open the file and make sure it contains only demo data
(no real student names, emails or bookings). Keep two demo accounts:
one student and one admin.
